# Dachshund70 wired plate

The switch plate for the wired mainboard (`hardware/Dachshund70-Wired/`): the same 1.6 mm FR4 plate as
`hardware/Dachshund70-Plate/` (outline, gasket nubs, encoder notch, accent rings), with only the 6.25u spacebar
(77 switch cutouts, 4 stabilisers) and no indicator-LED windows (the per-key LEDs shine through the switches).
DRC clean.

Generated by the original plate's script with the wired mainboard as input, from the repo root:

    PLATE_MAINBOARD=hardware/Dachshund70-Wired/Dachshund70-Wired.kicad_pcb \
    PLATE_OUT=hardware/Dachshund70-Wired-Plate/Dachshund70-Wired-Plate.kicad_pcb PLATE_LED_REFS= \
    "C:/Program Files/KiCad/10.0/bin/python.exe" hardware/Dachshund70-Plate/gen_plate.py

`Dachshund70-Wired-Plate-outline-v01.dxf` is its outline; STEP in `hardware/step/Dachshund70-Wired-Plate-v01.step`.
